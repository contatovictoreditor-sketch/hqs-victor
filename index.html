Configure sua chave da API do Google Drive

Esse site lê o conteúdo das pastas do Drive em tempo real. Para isso funcionar, você precisa de uma chave de API gratuita do Google Cloud (leva ~2 minutos).

  1. Acesse console.cloud.google.com e crie um projeto (qualquer nome, ex: leitor-hq).
  2. No menu, vá em APIs e Serviços → Biblioteca, busque Google Drive API e clique em Ativar.
  3. Vá em APIs e Serviços → Credenciais → Criar credenciais → Chave de API.
  4. Copie a chave gerada e cole no campo abaixo.
  5. Recomendado: clique na chave criada, em Restrições de API selecione apenas Google Drive API, e em Restrições de aplicativo escolha Sites e adicione o domínio onde este site ficar publicado. Isso evita uso indevido da chave.
